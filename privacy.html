privacy

this website is a static portfolio. it uses no cookies, no contact form, no analytics and no tracking. the typefaces are hosted on this site, so no data goes to font providers.

hosting. the site is hosted on github pages (github inc., usa). when you open it, github processes your ip address and technical request data (browser, time) in server logs. this is necessary to deliver the site (art. 6(1)(f) gdpr).

external links. links to instagram, soundcloud, spotify and others lead to third-party sites with their own privacy policies.

your rights. access, correction, deletion, restriction, objection, and a complaint to a data protection authority.
